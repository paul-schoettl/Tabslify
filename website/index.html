Häufig gestellte Fragen

Ist Cloud wirklich kostenlos? +
Ja, Cloud ist vollständig Open Source und kostenlos nutzbar. Du kannst es auf GitHub herunterladen und selbst kompilieren.
Welche Android-Versionen werden unterstützt? +
Cloud ist kompatibel mit Samsung OneUI 8.5. Die genauen Mindestanforderungen findest du in der GitHub-Dokumentation.
Werden meine Daten an Server gesendet? +
AI-Anfragen werden an Nvidia / Google weitergeleitet. Alle anderen Funktionen arbeiten standardmäßig lokal. Optionale lokale Auswertungen (z. B. Musik-Analyse) sind standardmäßig aus und nur nach deiner Zustimmung aktiv.
Wie kann ich beitragen? +
Du kannst auf GitHub Issues öffnen, Feature-Anfragen stellen oder Code beitragen. Jede Hilfe ist willkommen!
